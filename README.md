# Gere

Editor liviano de proyectos para Linux, hecho con Rust y GPUI. Permite revisar y editar archivos, además de operar sobre el índice y el árbol de trabajo de Git. La interfaz está inspirada en VS Code y usa **One Dark Pro Darker** por defecto.

## Requisitos

- Rust stable reciente (GPUI 0.2.2; Rust 1.80 no alcanza).
- Git y ripgrep (`rg`) disponibles en `PATH`.
- Dependencias de Linux de GPUI (X11 o Wayland, Vulkan, bibliotecas de desarrollo de XKB y fuentes). En Ubuntu 24.04 instala `sudo apt install libxkbcommon-dev libxkbcommon-x11-dev` antes de compilar. Consulta la documentacion de GPUI para otras distribuciones.

`cargo run --release -- /ruta/al/proyecto` abre el directorio indicado; sin argumento, usa el directorio actual.

## Uso

- La barra de iconos izquierda alterna entre archivos, búsqueda de texto y Git. En archivos hay un explorador de carpetas expandibles (carpetas primero; hasta 500 elementos visibles). Click en cualquier lugar de la fila de una carpeta para expandirla o contraerla; el botón junto al nombre del proyecto contrae todas las carpetas. `Ctrl+P` abre la búsqueda rápida de archivos (`rg --files`); usa ↑/↓ para elegir, Enter para abrir y Esc para cerrar. Escribí `archivo:500` para abrir la línea 500 de ese archivo, o `:500` para ir a esa línea del archivo actual. Cierra una pestaña con la X o haciendo click medio sobre ella.
- El engranaje al pie de la barra lateral abre **Configuración**. Elegí entre One Dark Pro Darker y One Dark Pro, cambiá la fuente del editor (Geist Mono, JetBrains Mono, Fira Code o monospace) y ajustá su tamaño entre 10 y 24 px. Los cambios se guardan automáticamente en `$XDG_CONFIG_HOME/gere/settings.json` (o `~/.config/gere/settings.json`) y se recuperan al iniciar. Cerrá el panel con Esc o la X. Para que una fuente seleccionada se vea como corresponde, debe estar instalada en el sistema.
- La lupa de la barra izquierda abre la búsqueda global de texto. Los resultados se actualizan mientras escribís, agrupados por archivo y por coincidencia; click en el nombre del archivo expande o contrae sus resultados y click en una coincidencia abre el archivo y selecciona ese texto. Las líneas largas muestran el fragmento alrededor de la coincidencia. Los campos de búsqueda global y Ctrl+F admiten Ctrl+A/C/X/V, Ctrl+Backspace/Delete, Home/End, flechas y selección con Shift. Podés volver a editar el archivo haciendo click en el código, y abrir Ctrl+F aun mientras el buscador global tiene el foco. Los controles permiten distinguir mayúsculas (**Aa**), coincidir con la palabra completa (**Palabra**), usar expresiones regulares (**Regex**) e incluir archivos ignorados por Git (**Ignorados**). Por defecto la búsqueda es literal, ignora mayúsculas y respeta `.gitignore`; nunca busca dentro de `.git`.
- La vista Git agrupa los cambios staged y sin stage, muestra la cantidad de archivos por grupo y las líneas agregadas en verde y eliminadas en rojo por archivo. El codigo XY de `git status --porcelain` indica el indice (X) y el arbol de trabajo (Y); `??` indica archivo nuevo. Click izquierdo en cualquier lugar de la fila abre automáticamente el diff en paralelo; click con la ruedita abre el archivo editable. Al pasar el mouse por una fila sin stage aparece **+** para agregar ese archivo a stage; sobre una fila staged aparece **−** para quitarlo. En archivos con conflictos, click izquierdo abre el editor con acciones **Aceptar actual**, **Aceptar entrante** y **Aceptar ambos** para resolver cada bloque; guardá con Ctrl+S y luego hacé Stage. También podés usar **Stage**, **Unstage** o **Descartar** (requiere segundo click). Descartar un archivo nuevo lo borra definitivamente.
- Escribe un mensaje y pulsa **Commit** para confirmar solo los cambios staged. **Stash** guarda cambios rastreados y archivos nuevos no ignorados; la lista de stashes permite **Aplicar** sin borrar el stash guardado. Los errores de Git aparecen en la barra inferior.
- El botón **Diff** permite alternar entre el archivo y la comparación contra HEAD, con dos paneles por defecto o un diff unificado. El panel izquierdo muestra el archivo completo en HEAD: es de solo lectura, pero permite seleccionar con el mouse, Ctrl+A y copiar con Ctrl+C. El derecho muestra el archivo completo actual, editable con los atajos habituales y Ctrl+S. Arrastrá la línea divisoria para cambiar el ancho de cada panel; ambos tienen scroll vertical y horizontal independientes cuando el contenido no entra. En el diff las líneas eliminadas se resaltan en rojo y las agregadas en verde (incluso al editar). Al abrir normalmente un archivo modificado, el código no se resalta: una línea fina junto al número de línea y las marcas del scroll indican los cambios. Al abrir el diff se centra el primer cambio en ambos paneles. Los archivos nuevos sin seguimiento se comparan contra un archivo vacío. La barra inferior indica el branch actual.
- El editor admite escritura, click para ubicar el cursor, arrastre para seleccionar, doble click para seleccionar una palabra y triple click para seleccionar una linea. El cursor de texto titila y el puntero cambia a I al pasar sobre el codigo. Atajos: Ctrl+A/C/X/V, Ctrl+Z/Y/S, Ctrl+F para buscar en el archivo, Enter/Shift+Enter para recorrer resultados, Ctrl+D para seleccionar la siguiente coincidencia, Ctrl+Left/Right para palabras, Ctrl+Backspace/Delete para borrado por palabra, Ctrl+Home/End para inicio/final del archivo, flechas, Home/End, Backspace/Delete, Enter, Tab y Alt+Up/Down para mover lineas. La busqueda permanece abierta al volver al codigo; usa Esc o × para cerrarla. Las barras de scroll vertical y horizontal aparecen solo cuando hay contenido fuera de vista y se pueden arrastrar. Ctrl+V conserva los saltos de linea en el editor; en busqueda, paleta y mensaje de commit se mantiene la insercion en una sola linea.
- La fuente inicial es Geist Mono. En Linux se instala en `~/.local/share/fonts`; si no está disponible en otro equipo, instalala desde [Vercel Geist](https://github.com/vercel/geist-font) (licencia SIL Open Font License).
- La lectura y el resaltado inicial de archivos se hacen en segundo plano. Explorador, codigo y diff dibujan solo las filas visibles para mantener fluido el scroll.
- Cada dos segundos se vuelven a leer los archivos abiertos, el explorador y el estado Git. La búsqueda global se vuelve a ejecutar al editar la consulta o sus opciones.

## Limites

Resaltado tree-sitter basico para Rust, JSON, HTML, CSS, Less y JavaScript; otros formatos son texto plano. Archivos binarios, no UTF-8 o mayores a 2 MB no se abren. La busqueda lateral y el mensaje de commit usan teclas y Ctrl+V, sin IME. La seleccion con mouse es de un solo cursor; no incluye multicursor, LSP, extensiones, depurador ni IA. Descartar opera sobre cambios no staged y archivos nuevos; los cambios staged permanecen intactos. Ejecuta la herramienta sobre repositorios de confianza: editar y las acciones Git modifican el arbol de trabajo.
